# Visual Design System

## 设计方向

新版视觉方向为：现代编辑式排版 + 克制的技术感 + 个人研究工作台。

要求：

- 精致但不花哨。
- 技术感明确，但不套用赛博朋克模板。
- 内容层级优先。
- 深浅主题完整支持。
- 默认遵循系统主题。
- 桌面端与移动端同等重要。
- 不使用大面积霓虹、玻璃拟态、渐变背景或无意义循环动画。
- 不展示虚假的技能熟练度、项目数量、工作年限或访问数据。

## 设计变量

颜色、边框、圆角、阴影、内容宽度和字体在 `src/app/globals.css` 中集中定义为 CSS 变量。

深色主题核心变量：

- background: `#090B0F`
- surface: `#11141A`
- elevated: `#151922`
- text-primary: `#F4F6F8`
- text-secondary: `#9CA3AF`
- border: `rgba(255,255,255,0.08)`
- accent: `#4F8CFF`

浅色主题使用冷灰白背景和清晰边框，不使用刺眼纯白作为页面整体背景。

## 字体

- 英文、数字与界面：Geist Sans。
- 代码：Geist Mono。
- 中文：系统中文字体栈。
- 不额外加载大型中文字体文件。

## 排版

- 正文默认 16px 级别。
- 文章正文最大宽度约 720-760px。
- 普通页面内容最大宽度约 1200px。
- 卡片使用细边框、轻阴影和适度圆角。
- 焦点状态必须清晰。

## 可访问性

- 支持键盘导航。
- 使用语义化 HTML。
- 图标按钮必须有可访问名称。
- 颜色对比度保持可读。
- 支持 `prefers-reduced-motion`。
- 320px 宽度下不产生横向滚动。
