# Visual Design System

## 设计方向

新版视觉方向为：现代编辑式排版 + 克制的技术感 + 个人研究工作台。

要求：

- 精致但不花哨。
- 技术感明确，但不套用赛博朋克模板。
- 内容层级优先。
- 深浅主题完整支持。
- 默认遵循系统主题。
- 桌面端与移动端同等重要。
- 不使用大面积霓虹、玻璃拟态、渐变背景或无意义循环动画。
- 不展示虚假的技能熟练度、项目数量、工作年限或访问数据。

## 第二阶段首页设计

第二阶段首页已经从第一阶段占位内容替换为正式结构：

- Hero：左侧为姓名、定位、主标题、简介、项目与笔记 CTA，右侧为通信与信号主题的内联 SVG 视觉模块。
- Current Focus：展示无线通信、物理层安全、嵌入式与物联网三张非链接卡片。
- Featured Project：展示已确认的智能家居 IoT 系统，并使用真实旧站截图。
- Knowledge Base：展示前端基础、物联网基础、数据采集与网关三类笔记入口，均链接到 `/notes`。
- About CTA：引导到 `/about`，不展示未经确认的联系方式或合作文案。

通信视觉模块只使用 React、CSS 和内联 SVG，不使用外部图片、Canvas、WebGL、3D 库或动画库。SVG 装饰内容使用 `aria-hidden`，轻微脉冲动画受 `prefers-reduced-motion` 控制。

## 设计变量

颜色、边框、圆角、阴影、内容宽度、区块间距和字体在 `src/app/globals.css` 中集中定义为 CSS 变量。

深色主题核心变量：

- background: `#090B0F`
- surface: `#11141A`
- elevated: `#151922`
- text-primary: `#F4F6F8`
- text-secondary: `#9CA3AF`
- border: `rgba(255,255,255,0.08)`
- accent: `#4F8CFF`

浅色主题使用冷灰白背景和清晰边框，不使用刺眼纯白作为页面整体背景。

第二阶段补充：

- `--section-spacing` 统一控制首页区块间距。
- `--accent-muted` 仅从核心蓝色强调色派生，不引入第二强调色。
- 交互反馈以边框、背景、轻微位移和清晰 focus ring 为主，阴影保持克制。
- 不强制全站平滑滚动。

## 字体

- 英文、数字与界面：Geist Sans。
- 代码：Geist Mono。
- 中文：系统中文字体栈。
- 不额外加载大型中文字体文件。

## 排版

- 正文默认 16px 级别。
- 文章正文最大宽度约 720-760px。
- 普通页面内容最大宽度约 1200px。
- 首页区块间距移动端约 64px，桌面端约 96-112px。
- 卡片使用细边框、轻阴影和适度圆角。
- 焦点状态必须清晰。

## 共享组件

- `Card` 默认不产生 hover 边框变化；只有 `interactive` 变体可出现 hover 与 focus-within 状态。
- `CardTitle` 支持 `h2`、`h3`、`h4`，用于保持页面标题层级连续。
- `PageHeader` 用于非首页页面骨架，排版与首页方向保持一致。
- Header 保持 sticky，并做轻量背景处理；移动导航焦点管理不应退化。
- Footer 继续隐藏 Research 和 Blog，直到正式内容准备完成。

## 响应式规则

- 首页从 320px 起不应出现横向滚动。
- Hero 在移动端为单列，文案优先，视觉模块位于文案下方。
- CTA 在窄屏下纵向排列。
- Featured Project 在移动端先显示说明，再显示截图；截图使用 `object-contain`，避免裁剪关键界面。
- 宽屏内容最大宽度仍由 `--content-width` 控制。

## 可访问性

- 支持键盘导航。
- 使用语义化 HTML。
- 图标按钮必须有可访问名称。
- 颜色对比度保持可读。
- 支持 `prefers-reduced-motion`。
- 320px 宽度下不产生横向滚动。
- 首页只有一个 `h1`。
- 首页各 section 使用 `aria-labelledby`。
- 项目截图 alt 为“智能家居客户端界面截图”。
